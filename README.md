# Arefi ITPraxis

Praktische Vorbereitung auf den Job als IT-Techniker, IT-Support und Junior-Systemadministrator – auf Persisch, Deutsch und Englisch.

- **Handy (Android/iPhone):** https://arefi2027.github.io/arefi-itpraxis/ öffnen und „App installieren“ bzw. „Zum Home-Bildschirm“ wählen.
- **Windows, macOS, Linux:** Installationsdateien unter [Releases](https://github.com/arefi2027/arefi-itpraxis/releases/latest).

## Sicherheit

- Updates der PC-Programme werden nur installiert, wenn `version.json` mit dem Ed25519-Schlüssel des Projekts signiert ist (`version.json.sig`) und die SHA-256-Prüfsumme der heruntergeladenen Datei stimmt.
- Die Web-App lädt keine fremden Skripte (Content Security Policy) und speichert den Lernstand nur auf dem eigenen Gerät.
- Sicherheitsprobleme bitte nicht öffentlich melden, sondern über „Security → Report a vulnerability“.
